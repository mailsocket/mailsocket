Database backups may retain deleted messages for up to 14 days, and undelivered mail may sit in the mail queue for up to 5 days before final deletion.

What OTP formats are detected, and with what confidence?

We extract candidate codes of 4 to 8 digits (or groups like 123-456) and give each a heuristic score between 0 and 1 (otp_confidence; fixed rules, not a trained model). A candidate near a verification keyword (such as code, OTP, verification, passcode, PIN) scores 0.95; an unlabelled numeric candidate scores 0.35. Order numbers, invoice totals, ZIP codes, phone numbers and years are rejected. Pass min_confidence to the wait endpoint to only accept codes above a threshold.

Do you follow magic links?

No. We extract the most likely magic link from the message body and return it in the magic_link field. We never click or follow it; your test opens the link.

What happens to mail if mailsocket is down?

Our mail server accepts a message only after it has been stored in the database. If storing fails, the message stays in the mail server's queue and delivery is retried for up to 5 days. If our mail server itself is unreachable, the sending server keeps the message and retries, as SMTP requires. A wait that is open during an outage returns an error or 204; call it again once the API responds.

How do I erase my data (GDPR)?

Delete your account from Settings. This permanently erases your account, inboxes and messages. Database backups may keep erased data for up to 14 days. For access or correction requests, email privacy@mailsocket.app.

How do I report a problem?

Use Report a problem (also in the footer, and in the dashboard sidebar when you are signed in). Include the request_id from the API error body or the reference shown on an error page, and the page you were on: that lets us find the request in our logs in seconds. A person reads every report and replies by email within 1 business day. Please don't paste API keys or one-time codes.

Do you support SMS?

No. mailsocket receives email only.

Do you return attachments?

Not yet. We extract the subject, From/To/Cc, the plain-text and HTML bodies, the OTP and the magic link. Attachment bodies are skipped (never treated as message text) but are not returned as files.
