Before you start

  • Create an inbox and an API key. Start free, verify your email, and open the dashboard. Your first inbox is created automatically, and you can create an API key in one click. Or use the 60-second path with no signup.
  • Copy your inbox address. It is <routing_key>@{{ mail_domain }}. The inbox id (inbox_…) is not the routing key, so copy the full address from the dashboard.
  • Point your signup form at that address. Replace https://app.example.com/signup and the selectors below with your real form.

The flow

  1. Note the time just before you submit (the start point).
  2. Submit the signup form with the mailsocket inbox address.
  3. Call GET /api/v1/inboxes/{id}/messages/wait with require=otp and since= the start point, so an email that arrives before the wait call starts is still matched. It returns the OTP as soon as it arrives, or 204 after 25 seconds; on 204, call again.
  4. Assert the OTP is present and has the expected shape (for example 4 to 8 digits).

Copy-paste example

Read your API key from the environment; never hardcode it. Set MAILSOCKET_API_KEY, MAILSOCKET_INBOX_ID and MAILSOCKET_INBOX_ADDRESS before running.
